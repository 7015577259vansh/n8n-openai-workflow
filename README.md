# 🤖 n8n OpenAI Workflow  

This repository contains my **n8n workflow** that connects with the **OpenAI API** to power an AI Agent.  
It can receive chat messages, process them using the OpenAI Chat Model, and respond dynamically.

---

## 🧩 Technologies Used  
- **n8n** (No-code automation)  
- **OpenAI Chat Model (GPT)**  
- **Simple Memory Node**  
- **Calculator Node**  
- **SerpAPI** (for web data retrieval)

---

## ⚙️ How It Works  
1. The workflow triggers automatically when a chat message is received.  
2. The message is processed by the **OpenAI Chat Model** node.  
3. The **AI Agent** uses memory, tools, and logic nodes to generate a reply.  
4. The response is then sent back to the chat interface.

---

## ⚠️ Important Note  
API keys and credentials are **not shared publicly** — they are stored securely inside **n8n**.
