# n8n OpenAI Workflow 🤖

This repository contains my **n8n workflow** that connects with the **OpenAI API** to power an AI Agent.  
It can receive chat messages, process them using the OpenAI Chat Model, and respond dynamically.

### 🔧 Technologies Used
- n8n (No-code automation)
- OpenAI Chat Model (GPT)
- Simple Memory node
- Calculator node
- SerpAPI (for web data)

### 🚀 How it works
1. The workflow triggers when a chat message is received.  
2. The message is passed to the OpenAI Chat Model node.  
3. The AI Agent processes the response and sends it back.  

### ⚠️ Note
API keys and credentials are **not shared publicly** — they’re stored securely inside n8n.
